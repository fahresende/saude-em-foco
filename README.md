
# 🩺 Saúde em Foco

### Tecnologia e saúde em um só lugar.

## 📌 Sobre o projeto

O Saúde em Foco é um projeto acadêmico desenvolvido com o objetivo de criar uma solução digital voltada à área da saúde.

## 🎯 Objetivo

Desenvolver uma plataforma intuitiva, acessível e organizada, proporcionando uma melhor experiência aos usuários.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📂 Arquivos do projeto

- `index.html` — Página principal.
- `Saude_em_Foco_5W2H_Requisitos` — Documento de requisitos do projeto.

## 👨‍💻 Desenvolvimento

Projeto desenvolvido como parte das atividades acadêmicas do curso de Análise e Desenvolvimento de Sistemas.
